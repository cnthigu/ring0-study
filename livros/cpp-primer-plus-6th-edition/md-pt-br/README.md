## Sobre esta traducao

Traducao do livro **C++ Primer Plus** para o **portugues brasileiro**, feita com auxilio de IA. O livro cobre toda a linguagem C++ a partir do C++11, indo do basico (variaveis, IO, controle de fluxo) ate templates, exceptions, classes com memoria dinamica, heranca, STL e o novo padrao C++11.

Criterios de traducao:

- Todo texto narrativo e explicativo traduzido para PT-BR natural e fluente — **sem resumos, sem omissoes**
- Termos tecnicos consagrados mantidos em ingles na primeira ocorrencia com parentese PT-BR: "alocacao dinamica (dynamic memory allocation)"
- Nomes de funcoes/classes da std mantidos em ingles
- Palavras-chave da linguagem nao sao traduzidas
- Nomes de variaveis e funcoes definidas pelo usuario traduzidos nos exemplos de codigo
